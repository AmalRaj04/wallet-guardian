# 📊 Demo Metrics - What to Show and Say

## The Situation

You revoked an approval, but the metrics (Threats Blocked, Funds Protected) didn't increase.

## Why This Happens

The metrics currently track **automatically detected threats**, not manual revocations through the UI.

---

## 🎬 How to Handle This in Your Demo

### Option 1: Focus on What Works (RECOMMENDED)

**What to show:**

1. ✅ Approval appears in list
2. ✅ Risk level detected (Critical/High/Low)
3. ✅ Click "Revoke" button
4. ✅ Transaction confirms
5. ✅ Approval disappears from list

**What to say:**

```
"Here's a critical unlimited approval that was detected.
With one click, I can revoke it to protect my funds.
[Click Revoke]
The system makes it easy to remove dangerous approvals.
[Wait for confirmation]
And it's gone - my funds are now protected."
```

**Don't mention the metrics** - Focus on the functionality that works perfectly!

---

### Option 2: Explain the Metrics

If asked about metrics:

**What to say:**

```
"The metrics track threats that are automatically detected
and blocked in real-time. The revoke feature gives you
manual control to remove any approval you want.
Both work together to keep your wallet secure."
```

## 📊 What the Metrics Actually Track

For your understanding (don't need to explain in demo):

### Threats Blocked:

- Automatically detected suspicious transactions
- MEV attacks prevented
- Sandwich attacks blocked
- Front-running attempts stopped

### Funds Protected:

- Value of tokens that would have been at risk
- Calculated from blocked threats
- Automatic protection value

### Manual Revocations:

- Currently don't update these metrics
- Could be added in future
- Focus on the revoke functionality itself

## 🚀 Pro Tip

If you want to show metrics increasing:

1. **Create multiple approvals** (3-4)
2. **Show them all in the list**
3. **Revoke them one by one**
4. **Say:** "I've protected X tokens across Y approvals"
5. **Calculate manually:** "That's $XXX in value protected"

This gives the same impact without needing the automatic metrics!
