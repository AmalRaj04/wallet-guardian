## 🎯 How to Start Monitoring Now

### Option 1: Click the Big Button

1. Look for the **orange banner** at the top that says "Monitoring Paused"
2. Click the **"Start Monitoring"** button on the right side
3. Status changes to "Active" ✅

### Option 2: Use Header Button

1. Look at the top-right corner of the dashboard
2. Click the **"Start Monitoring"** button (blue)
3. Monitoring activates immediately

### Option 3: Auto-Start (if you have tokens)

- Monitoring will auto-start when you have tokens in your portfolio
- Just connect wallet and it should activate

## 🔧 Troubleshooting

### Button doesn't work?

- Check browser console for errors
- Make sure wallet is connected
- Try refreshing the page

### Still shows paused after clicking?

- Check if there are any console errors
- Verify you're on Sepolia network
- Make sure you have some ETH for gas

### No transactions showing?

- Monitoring must be "Active" first
- Then create approvals (see guide)
- Wait 10-30 seconds for detection
